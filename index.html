🔍 Stock Market Screener & Moving Average Engine

Real-time multi-factor equities screening against price momentum, 15-day moving averages (MA15), and statistical volume surges.

Data Source: AlphaVantage (Real Ingestion / Seed Cache)

Platform Rule Logic & Calculation Methodology

• 15-Day Moving Average (MA15): Calculated as the unweighted arithmetic mean of closing prices over the prior 15 completed trading sessions: \(\bar{P} = \frac{1}{15}\sum_{i=1}^{15} P_{t-i}\). If fewer than 15 historical sessions exist in the dataset, the value is honestly labeled as N/A (Insufficient Data) without inventing synthetic metrics.
• Price vs. MA15 Rule: A stock is flagged Above MA when \(\text{Latest Close} > \text{MA15}\) indicating positive short-term momentum; and Below MA when \(\text{Latest Close} < \text{MA15}\).
• Unusual Volume Surge Rule: Triggers when current session trading volume satisfies \(\text{Volume}_{\text{today}} > 1.25 \times \text{AvgVolume}_{15}\) (>25% above its trailing 15-day average volume).
• Integrity Guarantee: All source records reflect ingested AlphaVantage data. Missing values are left null/N/A rather than fabricated.

End-to-End Pipeline Data Flow

[1. Alpha Vantage API]
↓ REST requests paced to 12s intervals (free-tier rate limitation compliance)
[2. Python Ingestion Client (src/ingestion/kafka_producer.py)]
↓ Publishes serialized JSON payloads with symbol partition key
[3. Apache Kafka 3.6 (Topics: stock-market-batch & stock-market-realtime)]
↓ Buffers message stream; raw consumer dumps to storage
[4. MinIO S3 Bronze Layer (raw/historical/year=YYYY/month=MM/day=DD/)]
↓ Raw immutable CSV objects stored with Hive-style folder partitioning
[5. Apache Spark 3.4 / PySpark Transformations (src/processing/batch_processing.py)]
↓ Cleans schema, calculates OHLCV daily rollups, moving averages (MA15, MA30), deduplicates via Window
[6. MinIO S3 Silver Layer (processed/historical/date=YYYY-MM-DD/symbol=TICKER/)]
↓ Snappy-compressed Parquet columnar partitions for high-throughput analytical reads
[7. Snowflake Gold Layer (DAILY_STOCK_METRICS via src/database/snowflake_loader.py)]
↓ Atomic MERGE INTO upsert prevents duplicates on retried pipeline runs
[8. TICKR Analytics Platform & Quality Dashboard]

Apache Airflow's Orchestration Role

Airflow orchestrates the DAG (airflow/dags/stock_market_pipeline_dag.py) on a daily schedule. It provides:
• Idempotency: Re-running a failed DAG run for any past date produces identical, conflict-free state in the warehouse.
• Retries & Alerting: Exponential backoff handles transient AlphaVantage rate limits.
• Sensor Dependency: Ensures ingestion finishes before triggering PySpark transformations.

Docker & Container Architecture

docker/docker-compose.yml spins up a complete multi-service stack:
• Kafka + Zookeeper: Message broker with dedicated listeners.
• MinIO: S3-compatible local bucket stock-market-data with console.
• Spark Master & Worker: Scalable compute with web UI at port 8080.
• Airflow Webserver, Scheduler, & Postgres: Orchestration management engine.
